# Tic Tac Toe 🎮

This is a simple Tic Tac Toe web application built using Flask for the backend and HTML, CSS, and JavaScript for the frontend.

##  Features
- Interactive Tic Tac Toe game
- Clean and responsive UI
- Backend powered by Flask
- Real-time game logic handling

## Tech Stack
- Python (Flask)
- HTML
- CSS
- JavaScript

##  Project Structure
- templates/ → HTML files
- static/ → CSS and JavaScript
- app.py → Flask backend
